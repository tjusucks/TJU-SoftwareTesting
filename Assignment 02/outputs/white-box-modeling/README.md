# White-Box Modeling (Integrated Mode)

Member5 places white-box modeling outputs in this directory.

Expected directory pattern:

- `{feature_id}/`
- Example: `article-lifecycle/`

Minimum files per feature:

- `report.md`
- `artifacts.json`

Optional:

- `revision_log.json` (only when revisions are applied)

All `artifacts.json` files must follow:

- `Assignment 02/schemas/white-box-output.schema.json`
